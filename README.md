# Resume evaluator

AI-powered tool to compare a resume to a job posting.

## Overview

* Job can be provided in a markdown file or as a link to a LinkedIn page.
* Job summarization
  * Score against resume `## SUMMARY:` section using text embedding.
* Extraction of job requirements
  * Scoring against resume `## SKILLS:` section using text embedding.
* Proposing changes to resume.
* Exporting report to markdown report.

See `makefile` for run options.
